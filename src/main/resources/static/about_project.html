About ShopHub

Academic Spring Boot Online Shop Prototype

Project Overview

ShopHub is an academic Spring Boot Online Shop prototype developed as part of the Software Development Methodologies course at university. This project serves as a comprehensive demonstration of modern web development practices, design patterns, and user interface principles.

The application showcases a complete e-commerce workflow including product browsing, shopping cart management, checkout process, user authentication interfaces, and order tracking. The UI is connected to a Spring Boot REST API with in-memory data storage to demonstrate real user actions during presentations.

This prototype emphasizes clean code architecture, responsive design principles, and intuitive user experience patterns commonly found in production-grade e-commerce platforms.

Purpose & Objectives

  • Demonstrate understanding of Spring Boot framework architecture and MVC patterns
  • Showcase modern front-end development skills with HTML, CSS, and Tailwind
  • Implement responsive design principles for optimal user experience
  • Create a professional UI prototype suitable for academic presentation
  • Apply software development methodologies in a practical e-commerce context

This is an academic prototype with real UI interactions and REST endpoints. Data is stored in memory for demonstration purposes (no database), and payment processing is simulated.
